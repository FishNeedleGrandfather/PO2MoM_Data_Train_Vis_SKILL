# Data, optimization, and evaluation contract

Read current `PO2MoM_TF/trainV7A.py`, `trainV7AllAngle.py`, `simulation_A/dataset/comb.py`, `simulation_smallbatch/dataset_builder_AllAngle.py`, and `record.md` before changing a run. These are a snapshot of the 2026-11-20 state, not a promise that future files are unchanged.

## Current A1 split

`comb.py` reads `dataset1_01.pt` through `dataset5_20.pt`, each with 93 angles. Within each of five geometry families, variant numbers 01–12 are X/train (60 geometries), 13–15 are V/validation (15), 16–20 are C/test (25). Each variant has 57 X/train angles: θ ∈ {35,45,55}, φ=0:10:180; 18 V/validation angles: θ ∈ {40,50}, φ=5:10:85; and 18 C/test angles: θ ∈ {40,50}, φ=95:10:175. Each of nine outputs is a *flat list of sample dicts*, named `dataset{variant_split}V{angle_split}A.pt`, with the literal V and A identifying dimensions.

`trainV7A.py` reads `datasetXVXA.pt` (3420 samples) for training and concatenates `datasetVVVA.pt` + `datasetVVCA.pt` (270+270) for validation and best-checkpoint selection. It does not use `CVCA` (25×18=450 samples): its C variants are held-out geometries. However, `VVCA` already uses the same C-angle set on V geometries for model selection. Therefore `CVCA` can test transfer to unseen *geometries* at those angles, but C is not a globally untouched angle set for this run. `VVCA` itself is validation data, not an independent test. Both validation files have 15 variants, with no overlap with the 60 train variants. The A1 geometry groups differ from the five fixed geometries used for the older all-angle checkpoint; confirm exact provenance when making claims about pretraining leakage or angle novelty.

The older `trainV7AllAngle.py` instead loads `simulation_smallbatch/datasets/dataset_case1to5_allangle_eta.pt` as a list of five top-level case dictionaries, taking θ/φ 10° multiples for train and θ∈{15,35,65,85}, φ%30=15 for validation (855/120 samples). It initialized from `case1_1ghz_bestV7_4_eta.pt`. Do not apply its nested data-reading loop to A1 flat files or compare validation MSE as if splits matched.

`comb.py` contains the expected per-file counts and checks each source variant's 57/18/18 angle coverage before saving. If verifying the saved files, load them read-only with `torch.load(..., map_location='cpu', weights_only=False, mmap=True)` and check lengths and disjoint `variant_id` sets; this can require gigabytes of memory. For cheap syntax validation of training code, use `python -m py_compile PO2MoM_TF/trainV7A.py`; do not import it, because import starts training.

## Scale and metrics

The builder uses `η₀=376.730313668`: `X[:,7:13]=η₀ J_PO`, `Y=η₀(J_MoM−J_PO)`, and `scale=1/η₀`. `K0` is the 1 GHz wavenumber; `k_hat` defines incidence. Training loss is mean over samples of `MSE(delta,Y)` where each sample's MSE averages its triangle/component entries; the PO baseline is `MSE(zeros_like(Y),Y)` on the same split. Neither number is a percent relative error, and they must not be used interchangeably with one.

For each sample, physical currents are `J_pred=(X[:,7:13]+delta)*scale`, `J_MoM=(X[:,7:13]+Y)*scale`. Relative current error is `||J_pred−J_MoM||_F / ||J_MoM||_F ×100%`, six real/imag components over all triangles, without area weighting. Compute this per sample, then state whether reporting a sample mean, a per-case mean followed by case-equal mean, or another aggregation. `scale` cancels inside a sample's relative ratio. MSE ratios do not determine this error because the MoM norm varies by sample.

## Existing V7A optimization and checkpoints

`trainV7A.py` loads only model weights from `checkpoints/case1_1ghz_bestV7_eta_all.pt`, uses `MG_NUM=4`, then creates *fresh* Adam at `lr=0.001`; loading optimizer state is commented out. It trains for 100 epochs, reduces LR by half after 20 consecutive non-improving epochs, and initializes `best_val_loss=inf`. `random.seed(42); random.shuffle(data_trains)` is called once before the epoch loop, so order is fixed across epochs. It accumulates five sample gradients as `(loss/5).backward()`, calls `optimizer.step()`, then `optimizer.zero_grad()` at every step. If changing batch size or the last batch becomes incomplete, scale that last batch appropriately. The 3420 current train samples divide evenly by five.

Validation is under `model.eval()` and `torch.no_grad()`. The checkpoint `checkpoints/case1_1ghz_bestV7_eta_comb.pt` saves epoch, model state, optimizer state, logged train loss, and validation loss whenever validation MSE improves. The logged train loss is accumulated during updates within the epoch, while validation loss is computed with the completed epoch's weights; for a fixed-checkpoint train metric, re-evaluate separately. `loss_historyV7_eta_comb.npy` saves the two 100-epoch curves only after the loop finishes. A best checkpoint is not automatically a faithful *resume* checkpoint for scheduler/patience, RNG, or in-epoch position.

`record.md` records experiment 19 (old all-angle split) with best epoch 204, validation correction MSE ≈0.01475297 vs PO MSE ≈0.1903792. Experiments 17/18 are invalid: gradient was not cleared after each batch step. Experiment 20 (A1 `XVXA`→`VVVA+VVCA`) reports best epoch 100, validation correction MSE 0.038437246, and separately recomputed average relative current error ≈30.18%/30.20% for `VVVA`/`VVCA`. It also reports SLICY as an independent-geometry observation; those numbers do not establish broad new-geometry generalization.

When proposing a new training design, explicitly decide whether the aim is angle interpolation on seen geometry, unseen A1 variants, unseen geometry families, or independent SLICY transfer. Choose geometry/angle partitions and a single checkpoint-selection set accordingly. To reserve C angles for final evaluation in a *new* run, select checkpoints using only V-angle validation (for example `VVVA`), avoid `VVCA` in selection/tuning, and evaluate C-angle files only after the design is fixed. Keep C geometries out of training/selection as well. This cannot retroactively make the already inspected C-angle results a blind test; if strict untouched evaluation is required after decisions informed by them, reserve new angles or geometries. Compare metrics only on identical samples and normalization, and state how the pretrained checkpoint's geometry and angles relate to the new evaluation set.
