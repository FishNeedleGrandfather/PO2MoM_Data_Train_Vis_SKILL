# Starting a new PO→MoM training experiment

Use this path for a new family such as `case6`, a chosen set of 12 incidence directions, and a new experiment ID. The count 12 does not determine train/validation/test membership. Do not copy the `trainV7A.py` top-level loop as a run configuration.

1. State the claim first: unseen geometry, interpolation/extrapolation to new angles, adaptation on a few case6 directions, or improvement on established A1 data. Define the final comparison and error aggregation. Give the experiment a distinct ID and output paths before any run; keep older checkpoints and histories intact.
2. Inventory the new samples: frequency, polarization and θ/φ convention, mesh triangle/index correspondence between PO and MoM, `X`/`Y`/`scale` normalization, `K0`, `k_hat`, `cluster`, `geo_edges`, `cpl_edges`, and complete 12-angle list. Check each sample's `[N0,13]`/`[N0,6]` shapes, finite values, nonempty clusters, edge bounds and unique angle IDs. Confirm whether its dataset is a top-level dict with `samples` or a flat list. Dataset creation and FEKO solves are separate work; this training skill starts from validated samples.
3. Decide the geometry and angle partitions together. A **sealed case6 evaluation** uses zero case6 samples in training, validation, hyperparameter tuning, or checkpoint choice; select on other geometries, then evaluate the predetermined 12 directions once. A **few-angle adaptation** uses an explicit subset of case6's 12 directions for fitting and a disjoint subset for evaluation; label it seen-geometry angle transfer. If only one case6 mesh exists, it cannot by itself establish unseen-case6-geometry generalization after adaptation. Reserve validation directions or use other validation geometries for checkpoint selection. Record all angle exposure in a pretrained checkpoint, too.
4. Choose architecture deliberately. [network.md](network.md) gives the verified V7 building blocks and shapes. For a changed number of MG calls, parameter sharing, attention heads, encoder widths, geometry/source features, fusion position, graph levels, decoder or normalization, trace the affected shapes and state-dict keys. Preserve V7's tangential six-component output if the target remains the same. Compare candidate designs on the same split; a multi-layer change is a new model variant, not just a renamed checkpoint.
5. Choose initialization: fresh model, strict compatible checkpoint, or documented partial transfer. Inspect source checkpoint epoch and provenance, compare state-dict keys/shapes, then decide whether Adam state, learning rate schedule, patience, RNG, and epoch count are restarted or faithfully resumed. Loading model weights alone is fine-tuning, not an exact resume. A pretrained fixed-geometry all-angle model may already have seen some of the selected incidence directions even if case6 geometry is new.
6. For a **training or few-angle adaptation** run, test one real *development/training* sample's forward shape, finiteness, tangent projection, correction MSE, zero-correction PO MSE, and backward gradient finiteness; then check a tiny training/validation loop, including `step()` followed by `zero_grad()`. Do not use sealed case6 samples for this fitting/debugging. For **zero-sample sealed case6 evaluation**, skip backward, optimizer steps, and all case6-based tuning; use only read-only data checks and final inference with the already fixed model. [scripts/check_contract.py](../scripts/check_contract.py) is a CPU-only synthetic structural check and does not validate real mesh, labels, or physics.
7. If training or adapting, set the training policy explicitly: sample order/shuffling frequency, accumulated samples per update and correct short-batch normalization, Adam and LR, decay/early stop, validation cadence, selection metric, best versus latest checkpoint, and separate paths for loss history. Preserve a final holdout that never selects a checkpoint. Verify `model.eval()` and `torch.no_grad()` for validation. A sealed zero-sample evaluation uses the already chosen checkpoint and has no fitting or selection step.
8. Report each split's correction MSE, its own PO MSE baseline, and per-sample current-relative error (with stated aggregation), plus any per-case/angle breakdown. Evaluate a fixed best checkpoint after training; online train loss and post-epoch validation loss refer to different weight states. Hand off data IDs, angle lists, code version, normalization, checkpoint path/epoch, `MG_NUM`, optimizer continuation policy, and limits of the generalization claim.

The following `trainV7A.py` values are **historical choices**, not case6 defaults: `datasetXVXA.pt` for train, `VVVA+VVCA` for validation, fixed `3420/540` sample counts, A1 `01–12/13–15/16–20` variant split, A1 `57/18/18` angle groups, `random.seed(42)` plus one shuffle before epochs, `batch=5`, `num_epochs=100`, `lr=0.001`, `patience=20`, `MG_NUM=4`, and `case1_1ghz_bestV7_eta_all.pt` initialization. New IDs and output names must not overwrite `case1_1ghz_bestV7_eta_comb.pt` or `loss_historyV7_eta_comb.npy`.

Minimal runnable structural check from the project root: `python -B -X utf8 PO2MoM_TF/SKILL/train_skill/scripts/check_contract.py`. When the skill is installed elsewhere, pass `--model-source /path/to/trainV7A.py`; the checker needs the project model source and PyTorch but does not import or execute the training loop. Optional `--checkpoint /path/to/checkpoint.pt` checks strict state-dict compatibility. For source syntax only, `python -B -m py_compile PO2MoM_TF/trainV7A.py` (importing that file executes training).
