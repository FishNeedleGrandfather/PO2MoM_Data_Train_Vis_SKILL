# Shared data and integrity contract

This is the existing 1 GHz η₀ schema to preserve when adapting an experiment. Check the source cards and units for any new frequency or polarization before claiming the same physical convention.

For `N` triangles, each sample contains `X` float32 `[N,13]`: triangle center `[x,y,z]`, unit normal `[nx,ny,nz]`, area, and six real/imag PO current components multiplied by η₀. `Y` float32 `[N,6]` equals η₀·(`J_MoM−J_PO`); `scale=1/η₀`, η₀=376.730313668 Ω. Multiply predictions by `scale` to recover physical residual current. `K0=2πf/c`, `k_hat` float32 `[3]` is `(-sinθ cosφ,-sinθ sinφ,-cosθ)`, plus integer-degree `theta`, `phi`, `num_triangles`. Positions retain the CAD origin; no global `r−r_c` conversion. Variant samples also carry `angle_group` and provenance in split lists.

`cluster.c01` `[N]` maps G0 triangles to G1, `cluster.c12` `[G1]` maps G1 to G2. Counts target `ceil(N/15)` G1 and `ceil(G1/15)` G2. Connected six-dimensional clustering uses `[center, 0.5×normal]`, seed 42 for KMeans, and geodesic weight 1.0. `geo_edges.e0/e1/e2` are undirected edge-pair tensors `[2,E]`: shared triangle mesh edge, then boundaries between clusters. `cpl_edges.e1/e2` have shape `[2,E]` and store each selected pair only once, with `i<j`; the dataset does not store reverse edges. For each `i`, the builder retains at most 32 eligible `j` at G1 within 5/3 wavelength, or 8 at G2 within 10/3 wavelength. Eligibility uses oriented normal-facing projections (at least cos75° toward the other node) and excludes near-parallel/opposite normals with absolute dot ≥ cos30°; candidates are ranked by `(1−normal_dot)/distance²`. The model's `Geo_cache` concatenates the stored indices in both orders when it consumes these coupling edges. Geometry tensors are shared by samples of the same mesh.

The builder requires ordered CFM/NAS triangle centers matching within 1e−6 m, nondegenerate triangles, method completion markers with PRE hash and triangle count, MoM `.out` convergence, and exactly one finite complex-current row per triangle with complete index coverage. Verify the expected direction set and mesh hash after reloading a saved dataset. Never construct from a partial MoM/PO pair or treat a `.done.json` alone as proof.
