# 验证口径与数据划分

以项目根目录为相对路径。对每次评估，先记录脚本、checkpoint 路径及 epoch、模型结构参数（例如 `MG_num`）、数据集、频率/极化、归一化、几何和方向划分、样本数。核对代码与实际数据后再复用旧记录中的数值。

## 电流、loss 和 PO 基线

- 数据中的 `X[:, 7:13]` 为归一化 PO 六维实数电流，`Y` 为归一化 MoM−PO 修正量。用样本 `scale` 恢复：`J_PO=X_J*scale`，`J_MoM=(X_J+Y)*scale`，`J_pred=(X_J+delta)*scale`。六维包含 xyz 的实部和虚部。
- 每个样本先算 `||J_pred−J_MoM||_F / ||J_MoM||_F × 100%`；PO 基线将 `J_pred` 换为 `J_PO`。明确是样本误差均值、各 case 等权均值，还是汇总范数；不要混用。分母接近零时标识异常，不能悄悄把误差当成正常值。
- 训练/验证 loss 通常是归一化修正量 `mean((delta−Y)^2)`，不是复电流相对误差。区分 checkpoint 日志的当轮 train loss、最佳 val loss、末轮 loss 和固定最佳权重的复算值；写明 epoch 与计算来源。
- 旧样本 PO 幅值归一化和统一 `eta0=376.730313668` 归一化的 MSE 尺度不同；相同样本的物理电流相对误差可统一口径比较。全角度、18 角度和多变体数据分布也不同，不把不同验证集的 MSE 差值直接解释为改进量。
- 电流着色的 `||Re J||_2`（t=0 实部三个分量范数）不是完整复电流幅值，也不是误差分母；网页和图注应据实标明。

## 划分与封存测试

- 六个固定几何的全角度计划：每几何 θ=10°:5°:90°、φ=0°:5°:180°，629 个方向。`record.md` 中全角度训练使用每几何 171 个训练方向、24 个验证方向；其余方向不可自动称为已完成独立测试。固定几何上的未见方向是新角度测试，不等于新几何泛化；属于角度插值还是外推，取决于角度域与具体划分，不能仅凭“留出”判定。
- 多变体五个 CAD 族、每族 20 变体。几何 X=01–12、V=13–15、C=16–20；角度 X 为 θ∈{35°,45°,55°}、φ=0°:10°:180°；V 为 θ∈{40°,50°}、φ=5°:10°:85°；C 为同 θ、φ=95°:10°:175°。文件名的几何字母与角度字母各有含义，先与实际 dataset metadata 核对。
- 当前 V7comb 使用 `datasetXVXA.pt` 3420 样本训练，以 `datasetVVVA.pt` 和 `datasetVVCA.pt` 各 270 样本验证选参。`VVCA` 的 C 角已用于当前 V7comb 选模，不能把该组当作独立封存测试，也不能据此作“C 角在全局均未参与选模”的结论；其他几何与 C 角组合是否仍可作独立测试，须按实际使用记录逐组判断。拟作最终 test 的几何/角度组合需在选参、调阈值和调展示之前冻结，记录名单与数据版本；若已查看并据此修改方案，标为开发/验证观察并另留新测试。
- SLICY、飞机和 `case_single` 是独立几何推理示例，应分别列样本数、角度和负面结果；不能据个别案例推断所有未见 CAD 家族的泛化能力。尤其飞机的电流 error 可比 PO 更差，即使单站 RCS RMSE 改善，也不能称整体成功。

## RCS

- 单站使用与入射方向相对应的回波观察方向，核对 `-k_hat` 的定义、频率、极化、单位 dBsm 和角度顺序。相同 φ 点上先求 dBsm 差，再算 `sqrt(mean((curve−MoM)^2))`，报告方向数、θ 和 φ 网格。PO、预测和参照的 RMSE 均相对同一 MoM 曲线。
- 双站需固定同一入射方向，列出每个观察 θ/φ、极化、单位和积分/FEKO 提取方式；按同一观测网格及同一口径计算误差。没有完整观察网格、极化或 MoM 对照时，只能展示曲线，不报严格双站 RMSE。
- 项目部分 RCS 由三角元复电流进行远场积分估算；SLICY 二次反射等曲线来自 FEKO 原生远场。两种来源并列时注明差异，可作趋势对比；严格量化结论须统一远场计算口径，并检查三角元顺序、面积、相位、极化、传播方向和归一化。
