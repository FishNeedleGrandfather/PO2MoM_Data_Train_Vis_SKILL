# 验证口径与数据划分

以项目根目录为相对路径。对每次评估，先记录脚本、checkpoint 路径及 epoch、模型结构参数（例如 `MG_num`）、数据集、频率/极化、归一化、几何和方向划分、样本数。核对代码与实际数据后再复用旧记录中的数值。

## 电流、loss 和 PO 基线

- 数据中的 `X[:, 7:13]` 为归一化 PO 六维实数电流，`Y` 为归一化 MoM−PO 修正量。用样本 `scale` 恢复：`J_PO=X_J*scale`，`J_MoM=(X_J+Y)*scale`，`J_pred=(X_J+delta)*scale`。六维包含 xyz 的实部和虚部。
- 每个样本先算 `||J_pred−J_MoM||_F / ||J_MoM||_F × 100%`；PO 基线将 `J_pred` 换为 `J_PO`。明确是样本误差均值、各 case 等权均值，还是汇总范数；不要混用。分母接近零时标识异常，不能悄悄把误差当成正常值。
- 训练/验证 loss 通常是归一化修正量 `mean((delta−Y)^2)`，不是复电流相对误差。区分 checkpoint 日志的当轮 train loss、最佳 val loss、末轮 loss 和固定最佳权重的复算值；写明 epoch 与计算来源。
- 不同归一化方案的 MSE 尺度可能不同；同一样本恢复物理电流后的相对误差才可统一口径比较。不同验证集或几何分布的 MSE 差值不能直接解释为模型改进。
- 电流着色的 `||Re J||_2`（t=0 实部三个分量范数）不是完整复电流幅值，也不是误差分母；网页和图注应据实标明。

## 划分与封存测试

- 对每个几何与方向组合列实际用途和依据，分别统计 train、val、封存 test 和尚未使用样本。验证选模、调阈值或反复查看结果用过的组合不能作为独立最终测试；拟作 test 的组合需事先冻结名单与数据版本。文件名中的 X/V/C 等字母只按对应 dataset 的实际元数据解释，历史含义见 [history.md](history.md)。
- 固定几何上的未见方向是新角度测试，不等于新几何泛化；属于插值还是外推取决于角度域和划分。新几何个别成功/失败不代表所有未见 CAD 家族，报告各自结果及负例；即使 RCS 改善，电流 error 变差也不能称整体成功。

## RCS

- 单站使用与入射方向相对应的回波观察方向，核对 `-k_hat` 的定义、频率、极化、单位 dBsm 和角度顺序。仅在真实且对齐的观测点上先求 dBsm 差，再算 `sqrt(mean((curve−MoM)^2))`，报告方向清单或实际网格及点数。PO 与预测的 RMSE 均相对同一 MoM 曲线；稀疏角度不能伪装成完整规则扫描。
- 双站需固定同一入射方向，列出每个观察 θ/φ、极化、单位和积分/FEKO 提取方式；按同一观测网格及同一口径计算误差。没有完整观察网格、极化或 MoM 对照时，只能展示曲线，不报严格双站 RMSE。
- RCS 可由三角元复电流远场积分估算，也可能来自 FEKO 原生远场。两种来源并列时注明差异，可作趋势对比；严格量化结论须统一远场计算口径，并检查三角元顺序、面积、相位、极化、传播方向和归一化。具体历史曲线见 [history.md](history.md)。
