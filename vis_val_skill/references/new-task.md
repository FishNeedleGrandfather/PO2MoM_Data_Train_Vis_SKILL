# 新任务：从输入到交接

本页给可变输入与产物路线，不预设六几何、17×37 网格、V7comb 或特定仓库。路径相对项目根目录。

## 先核对输入

| 字段 | 所需信息 |
| --- | --- |
| 模型 | checkpoint、epoch、模型定义、`MG_num`、归一化、训练/验证选模经历 |
| 数据 | dataset 及版本、几何、网格/NAS 顺序、频率/极化、`X/Y/scale` 语义、PO/MoM 电流和可用远场 |
| 方向 | 实际 `(theta,phi)` 清单、入射/观察定义、train/val/test/未使用标签及依据 |
| 交付 | 评估分组、loss 日志、编号记录、图/HTML、本地或发布、目标仓库 |

缺少训练日志则不编造 loss 曲线；缺少 MoM 则不能给以 MoM 为参照的电流 error/RCS RMSE。未知划分标“用途待确认”。

## 评估到交付

1. 对照模型定义加载 checkpoint，核对输入张量、六维电流/scale、几何与边索引；枚举方向，查重复、缺失、非有限值和网格三角元顺序。固定模型、dataset 和方向清单的可追溯路径/版本。判断是未见角度还是新几何，并追踪是否参与过选模。
2. 逐样本推理，汇总物理 `J_PO/J_MoM/J_pred`、修正量 MSE、完整复电流相对 error 与同批 PO baseline。按请求给逐方向、逐几何/分组和总体统计，说明样本均值/等权均值口径，并呈现模型比 PO 更差的负例。训练/验证 loss 取日志，区分日志值和 checkpoint 复算值。
3. 单站 RCS 用匹配的回波方向算同口径 PO/MoM/预测；双站先固定入射、观察方向与极化。只对真实存在且对齐的观测点算 dBsm RMSE；FEKO 原生远场和电流积分混用时单列来源限制。保留逐点数据及汇总，不只留截图。
4. 查 `record.md` 当前最大且未占用编号，按 [record.md](record.md) 更新输入、划分、曲线、指标、单位与负例；周志以新日期成节。新编号是可变值，不默认历史实例的“20”。
5. 导出电流、网格和 RCS 元数据，按 [visualization.md](visualization.md) 构建适合实际角度布局的页面并验收。只有用户要求发布时才按 [publishing.md](publishing.md) 推送与核验 Pages。

## 验收场景：case6、任意 12 个方向、新编号

列出 12 个真实 `(θ,φ)` 与各自用途。不能假定同 θ 的 φ 扫描，也不能将其送入硬编码 17×37 的全角度导出与页面。只评估实际 12 点；其他角度标“无样本/未评估”，不能补零或计入 RMSE。训练中未用但曾参与选模的组合标验证观察；只有事先冻结且从未选模的组合才称独立 test。若用途不明，暂标待确认。

以 `export_allangle_visualization.py` 的 checkpoint 加载、电流恢复、网格校验和积分为参考，参数化 checkpoint、dataset、几何键与显式角度清单；移除 `CASES`、`THETAS/PHIS`、`CURRENT_ANGLES` 的六几何/629 角断言，输出 schema 改为对齐的方向记录。`visualization/generate_allangle_viewer.py` 当前假定六几何、三电流方向和矩形 `rcs_db[3,theta,phi]`，应适配方向列表或新建 case6 生成器；`visualization/allangle/index.html` 当前按 θ 行、φ 列选曲线并写死说明，也需适配稀疏方向。多 θ 时用方向表或 θ/φ 散点标记 PO/MoM/预测；只在同 θ 下有足够 φ 点时绘该 θ 的 φ 曲线，不跨 θ 连成一条扫描线。未要求通用页面时可做独立 HTML。聚类/耦合 JS 从 case6 对应 dataset 生成，核对索引与网格。

验收：导出恰有 12 个不重复方向，缺失角度不显示也不进入 RMSE；电流 error 和 RCS RMSE 可由逐点表复算；页面可切换 12 个方向、标记划分、显示正确网格/边层，浏览器无资源错误；新编号在表、正文、曲线和图题一致。
